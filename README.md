## 🛠 Установка

1. [cite_start]Скачайте файлы из этого репозитория (кнопка **Code** -> **Download ZIP**). 
2. [cite_start]Распакуйте содержимое в корневую папку с установленной игрой `TVTower`. 
3. [cite_start]Запустите игру через `TVTower_Win64.exe` (или Win32 версию). 
4. [cite_start]При первом запуске выбрать язык ОТЛИЧНЫЙ от русского, начать новую игру. Потом через меню вернуться обратно на титульный экран.
5. [cite_start]В главном меню перейдите в **Settings** и выберите язык **Russian**.

## ⚠️ Технические особенности

[cite_start]Игра разработана на движке **BlitzMax**, который крайне чувствителен к кодировкам.  [cite_start]Все файлы перевода сохранены в формате `UTF-8 без BOM` (или `Windows-1251`), чтобы избежать вылетов.
